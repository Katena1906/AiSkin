# AI Дерматолог — интеллектуальная система диагностики заболеваний кожи

## О проекте

AI Дерматолог — это веб-приложение для анализа изображений кожи с использованием нейросетей. Система определяет тип заболевания, визуализирует проблемные зоны, формирует персональные рекомендации по лечению и уходу, включая предложения лекарственных препаратов через интеграцию с государственной базой данных RxNorm (Национальная медицинская библиотека США).

## Основные возможности

- Анализ загруженных фотографий кожи с помощью модели на базе EfficientNet-B0
- Определение 4 типов заболеваний: акне, актинический кератоз, базально-клеточная карцинома, розацеа
- Автоматическое определение здоровой кожи при низкой уверенности модели
- Визуализация проблемных зон с помощью Grad-CAM тепловых карт
- Генерация плана лечения на основе реальных лекарственных препаратов (RxNorm API)
- Разделение на безрецептурные и рецептурные препараты
- Предупреждения о рисках и необходимости консультации врача
- Рекомендации по ежедневному уходу (утро/вечер)
- Сезонные советы с учётом текущего времени года
- История анализов с сохранением в локальном хранилище
- Интерактивное модальное окно с деталями проблемных зон

## Технологический стек

**Бэкенд:**
- Python 3.10
- FastAPI — веб-фреймворк
- Pytorch — фреймворк глубокого обучения
- Torchvision — предобученные модели и трансформации
- RxNorm API — интеграция с медицинской базой лекарств
- Uvicorn — ASGI сервер

**Фронтенд:**
- React 18
- TypeScript
- Vite — сборка
- Axios — HTTP запросы
- React Dropzone — загрузка файлов

**Модель:**
- Архитектура: EfficientNet-B0
- Предобучение: ImageNet
- Аугментация: RandomHorizontalFlip, RandomRotation, ColorJitter
- Функция потерь: CrossEntropyLoss
- Оптимизатор: Adam
- Early stopping для предотвращения переобучения

**Результаты модели:**

| Класс | Precision | Recall | F1-score |
|-------|-----------|--------|----------|
| Акне | 0.85 | 0.82 | 0.84 |
| Актинический кератоз | 0.57 | 0.40 | 0.47 |
| Базально-клеточная карцинома | 0.91 | 0.78 | 0.84 |
| Розацеа | 0.51 | 0.75 | 0.61 |

**Общая точность: 70.75%**

## RxNorm API интеграция

RxNorm — открытый API Национальной медицинской библиотеки США, предоставляющий нормализованные названия лекарственных средств.

**Использованные возможности:**
- Поиск препаратов по действующему веществу
- Получение торговых названий и классов препаратов
- Информация о механизме действия
- Список побочных эффектов
- Маркировка рецептурных препаратов
- Предупреждения о рисках

**Маппинг заболеваний на действующие вещества:**

| Заболевание | Действующие вещества |
|-------------|----------------------|
| Акне | изотретиноин, третиноин, адапален, клиндамицин |
| Розацеа | метронидазол, азелаиновая кислота, ивермектин |
| Актинический кератоз | фторурацил, имиквимод, диклофенак |
| БКК | висмодегиб, фторурацил, имиквимод |

## Установка и запуск

### Требования
- Python 3.10+
- Node.js 18+
- 8GB RAM (рекомендуется)
- GPU (опционально, для ускорения)

### Бэкенд

```bash
# Клонирование репозитория
git clone https://github.com/Katena1906/AiSkin.git
cd AiSkin

# Создание виртуального окружения
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

# Установка зависимостей
pip install -r backend/requirements.txt

# Запуск сервера
python backend/app/web_app.py
```

Сервер запустится на `http://localhost:8001`

### Фронтенд

```bash
cd frontend
npm install
npm run dev
```

Приложение откроется на `http://localhost:3000`
